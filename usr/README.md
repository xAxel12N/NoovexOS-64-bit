# usr

User space.

| Folder | What is in it |
|---|---|
| `src/` | native NoovexOS programs and `nvxbox` (coreutils) |
| `libc/` | the native C library |
| `musl/` | musl programs and ports (SQLite, fetch, play, ...) |
| `glibc/` | glibc test programs |
| `x11/` | X11 programs (nvxwm, xdemo) |
| `bin/` | prebuilt user binaries |
| `packages/` | `.deb` packages built into the system |
| `mod/` | example kernel module |
