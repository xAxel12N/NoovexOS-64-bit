# Code of Conduct

This project follows the Contributor Covenant (version 2.1). By participating, you agree to abide by its terms.

Be respectful and considerate. Harassment, hate speech, and discriminatory language are not allowed. Treat others with kindness; assume good intent.

If you are subject to or witness unacceptable behavior, please open an issue or contact the repository owner privately.

For the full text, see: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
