# fs

File systems.

| Folder | What is in it |
|---|---|
| `vfs/` | the virtual file system, mounts, volumes and partitions, the Unix directory tree, the RAM file store, the sysroot |
| `nvx/` | NVX4, the native file system (extents, checksummed metadata), and the disk glue |
| `fat/` | FAT12/16/32 |
| `ntfs/` | NTFS through ntfs-3g |
| `pkg/` | `.deb`/`.apk` packages and the apt client |
