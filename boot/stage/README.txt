NoovexOS 64
===========
A from-scratch 64-bit operating system.

  boot/    kernel64.bin  - the kernel (loaded by the built-in bootloader)
  doom/    DOOM1.WAD     - FreeDoom Phase 1 game data (DOOM app)
  boot.cfg               - boot configuration

This image boots from CD or from a USB stick written with dd / Rufus (DD mode) / Etcher.
