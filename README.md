Short description

Quick start
1. Clone: git clone https://github.com/xAxel12N/NoovexOS-64-bit.git
2. Enter the repo: cd NoovexOS-64-bit
3. Build (example):
   - Install dependencies: <list deps>
   - Run: make build
4. Run in QEMU:
   - qemu-system-x86_64 -kernel build/kernel.bin
