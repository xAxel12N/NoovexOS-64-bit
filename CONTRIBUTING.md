# Contributing to NoovexOS

Thanks for your interest! This doc explains the simplest way to contribute.

1) Pick an issue
- Start with issues labeled `good first issue` or `help wanted`.
- If none exist, open an issue describing what you want to work on.

2) Fork -> Branch -> PR
- Fork the repo and create a feature branch: `git checkout -b my-fix`
- Commit small changes with clear messages.
- Push and open a PR describing the change and why.

3) PR checklist (keep PRs small)
- [ ] Includes a short description of the change
- [ ] Build/test steps added if needed
- [ ] Links to an issue (if any)
- [ ] Passes CI (if applicable)

4) Code style & tests
- Follow the repository’s coding conventions.
- Add tests or manual verification steps when possible.

5) Questions & communication
- If you need help, comment on the issue or open a draft PR — maintainers will help.

We’ll review PRs quickly and give friendly feedback. Thank you!
