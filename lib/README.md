# lib

Kernel libraries.

| Folder | What is in it |
|---|---|
| `base/` | formatting, memory and string functions, the small C library |
| `cxx/` | the C++ runtime (`new`/`delete`, global constructors) |
| `compress/` | xz, zstd and archive unpacking |
| `image/` | PNG and JPEG decoders |
| `js/` | the small JavaScript interpreter |
| `crypto/` | SHA, AES, TLS 1.3, WPA2 crypto, X.509 and the root certificates |
